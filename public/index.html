What this is

A real working CNC that is now a rebuild project

This machine is from the older BuildYourCNC blackToe DIY-router family. I built and used it for cutting sheet parts, signs and detailed routed work. I later disassembled it, and I am selling the machine in parts rather than rebuilding a table just to put it back into service.

The exact blackToe hardware revision has not been confirmed, so the linked BuildYourCNC instructions should be treated as reference material and compared to the actual parts shown here.

Important condition note

This is not a plug-in-and-cut machine today. It needs a new table/base, reassembly, alignment, a replacement stepper motor driver, and normal inspection/testing of the older electronics and wiring.

What the buyer needs to add

This is a capable project, not a turnkey machine

  1. Build a rigid table/base sized for the 2×4-class machine.
  2. Install the included T-slot aluminum extrusions and machine hardware on the new table.
  3. Reassemble and square the gantry and Z axis.
  4. Install the motors, chain drive, cable carrier and wiring.
  5. Replace the known-bad stepper motor driver.
  6. Supply and configure a control PC and CNC software.
  7. Inspect, test and calibrate the completed machine before use.
