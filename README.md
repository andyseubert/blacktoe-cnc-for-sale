# blackToe CNC for sale

Static sale site for a disassembled BuildYourCNC blackToe 2x4-class CNC router project.

## Local preview

The site is plain HTML/CSS/JS under `public/`.

```bash
cd public
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Cloudflare Pages deployment

Use Git integration with this GitHub repository.

- Production branch: `main`
- Build command: `exit 0`
- Build output directory: `public`

Cloudflare will publish the site at a `*.pages.dev` hostname and redeploy automatically after future pushes to `main`.
